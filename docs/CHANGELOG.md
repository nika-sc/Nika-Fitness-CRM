# Журнал изменений

Значимые изменения Nika Fitness CRM (self-hosted).

## 2026-08-23

- На телефоне: меню и модалки открываются, таблицы не вылезают за край, заявка с сайта клуба работает.
- Новый движок оформления: свой собранный CSS, без Bootstrap-классов в шаблонах.
- Страницы легче, шапка одинаковая на витрине, сайте клуба и ЛК.
- Форма входа не кэшируется; если сессия устарела — обновите страницу и войдите снова.
- Миграции не нужны. Обновите файлы и перезапустите службу.

## 2026-08-22

- Новый интерфейс на Tailwind + daisyUI (тёмная тема Nika Fit). AdminLTE и Bootstrap убраны.
- Страницы витрины, сайта клуба и ЛК стали легче: больше не подключают каркас рабочего места сотрудника.
- Цвет клуба из настроек применяется как тема, без перекраски чужих стилей.
- Готовый CSS в репозитории; Node.js на сервере клуба не нужен.
- Миграции не нужны.

## 2026-08-20

- Публичная шапка больше не ведёт в демо-клуб: вместо «Войти в демо» и «Сайт клуба» — кнопка «Войти».
- Кнопка «Варианты развёртывания» в документации заменена на «О продукте».
- Миграции не нужны.

## 2026-08-16

- Сайт клуба: витрина и запись гостя без личного кабинета.
- Заявки с сайта в CRM; место после подтверждения администратора.
- Новая установка с GitHub уже содержит это. Старая копия — `git pull` и миграции `018`, `019`.

## 2026-08-15

- Кабинет тренера: свои окна на неделю, заявки из ЛК, подтверждение, отметки прихода.
- Запись на персоналку из личного кабинета, карточки клиента и со стойки. Оплата отдельно.
- Лимит трёх незакрытых записей на клиента; двойной брони на одно окно нет.
- Ресепшен: таблица визитов за день с фильтром «В зале».
- Новая установка с GitHub уже содержит эти изменения. Кто обновляет старую копию — `git pull` и миграции `016`, `017`.

## 2026-08-14

- Стойка: живой поиск с трёх символов, статистика смены с сравнением периодов, чекин открывает карточку с фото сверки.
- Номера карт: новым клиентам — цифры с 1000; короткие VIP-номера выбираются вручную; старые `NF…` без изменений.
- Касса: статьи прихода и расхода, способы наличные / карта / QR; оплаты абонемента, гостя и PT пишутся в журнал смены.
- Интерфейс сотрудников: пункт **Обзор**, русские подписи ролей и статусов, сетка расписания с «Сегодня», блоки в настройках.
- CRM на телефоне: установка на домашний экран для сотрудников.
- Плановое обновление защиты; после обновления примените миграции.
- Руководство пользователя 1.3 и сценарий рабочего дня.

## 2026-08-08

- Новый responsive staff-интерфейс на локально vendored AdminLTE 4.2.0 / Bootstrap 5.3.8 в теме Nika Fit.
- Сгруппированное RBAC-меню, mobile sidebar, обновлённые cards/forms/tables и accessibility.
- USER_GUIDE и USER_WALKTHROUGH: подробные сценарии со скриншотами всех ключевых экранов (`docs/assets/walkthrough/`).
- Публичный README: оглавление, функции, установка Linux/Windows, архитектура, security (self-hosted).
- Issue templates (bug / feature), CONTRIBUTING / SECURITY для OSS-снимка.
- Блог и updates: публичный self-hosted, галерея CRM на лендинге.
- Публичные страницы: `/docs`, `/blog` (нововведения только в блоге).
- Миграция `012_booking_tracking` (источник записи, метки времени).
- Безопасная запись/отмена из ЛК и блоки portal-записей на dashboard.
- Расширенная аналитика клиента в ЛК (визиты, оплаты, лояльность, медсправка, PT).
- Документация установки для Linux и Windows.

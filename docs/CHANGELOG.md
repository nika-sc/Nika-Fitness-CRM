# Журнал изменений

Значимые изменения Nika Fitness CRM (self-hosted).

## 2026-08-14

- Стойка: живой поиск с трёх символов, статистика смены с сравнением периодов, чекин открывает карточку с фото сверки.
- Номера карт: новым клиентам — цифры с 1000; короткие VIP-номера выбираются вручную; старые `NF…` без изменений.
- Касса: статьи прихода и расхода, способы наличные / карта / QR; оплаты абонемента, гостя и PT пишутся в журнал смены.
- Интерфейс сотрудников: пункт **Обзор**, русские подписи ролей и статусов, сетка расписания с «Сегодня», блоки в настройках.
- CRM на телефоне: установка на домашний экран для сотрудников.
- Плановое обновление защиты; после обновления примените миграции.
- Руководство пользователя 1.3 и сценарий рабочего дня.

## 2026-08-08

- Новый responsive staff-интерфейс на локально vendored AdminLTE 4.2.0 / Bootstrap 5.3.8 в теме Nika Fit.
- Сгруппированное RBAC-меню, mobile sidebar, обновлённые cards/forms/tables и accessibility.
- USER_GUIDE и USER_WALKTHROUGH: подробные сценарии со скриншотами всех ключевых экранов (`docs/assets/walkthrough/`).
- Публичный README: оглавление, функции, установка Linux/Windows, архитектура, security (self-hosted).
- Issue templates (bug / feature), CONTRIBUTING / SECURITY для OSS-снимка.
- Блог и updates: публичный self-hosted, галерея CRM на лендинге.
- Публичные страницы: `/docs`, `/blog` (нововведения только в блоге).
- Миграция `012_booking_tracking` (источник записи, метки времени).
- Безопасная запись/отмена из ЛК и блоки portal-записей на dashboard.
- Расширенная аналитика клиента в ЛК (визиты, оплаты, лояльность, медсправка, PT).
- Документация установки для Linux и Windows.

## 1. Вход и роли

### 1.1. Адреса

| Раздел | URL |
|--------|-----|
| Вход сотрудников | `/login` |
| Dashboard | `/dashboard` |
| Стойка ресепшена | `/reception/` |
| Личный кабинет клиента | `/portal` |
| Публичный сайт клуба | `/club/` |
| Документация на сервере | `/docs` |

### 1.2. Экран входа

1. Откройте `/login`.
2. Введите логин и пароль сотрудника.
3. Нажмите **Войти**.

![Экран входа сотрудника](assets/walkthrough/01-login.png)

После первого входа **смените** пароль seed-админа (`admin` / значение из `ADMIN_PASSWORD`).

### 1.3. Роли

| Роль | Основной сценарий |
|------|-------------------|
| `owner` | Полный контроль клуба, дашборд, настройки, сотрудники |
| `admin` | Операционное управление, отчёты, расписание, клиенты |
| `reception` | Стойка ресепшена, чекин, продажи абонементов, гости |
| `trainer` | Просмотр расписания, клиентов и части operational-данных |

Важно: `owner` / `admin` открывают `/dashboard`, `reception` автоматически перенаправляется на стойку.

## 2. Dashboard

Раздел **Обзор клуба** (`/dashboard`) — стартовая точка для owner/admin.

![Dashboard — обзор клуба](assets/walkthrough/02-dashboard.png)

На панели:

- KPI: активные клиенты и абонементы, оплаты за 7 дней, заполняемость;
- записи из ЛК за 24 часа, отмены и no-show;
- блок **«Новые записи из ЛК»**;
- блок **«Группы сегодня»**;
- ближайшие записи и последние чекины.

Быстрые кнопки сверху ведут в расписание и на стойку ресепшена.

## 3. Ресепшен

Стойка: `/reception/`.

![Стойка ресепшена](assets/walkthrough/14-reception.png)

### 3.1. Чекин клиента

1. Отсканируйте QR из ЛК клиента **или** введите номер карты (`NF…`).
2. При необходимости выберите **зону доступа** (например, тренажёрный зал).
3. Нажмите **Отметить визит**.
4. Либо найдите клиента по ФИО / телефону / карте в поле поиска.

Система покажет статус абонемента и предупреждения (истечение, медсправка и т.п.).

### 3.2. Гостевой визит

В блоке **Гостевой визит**:

1. Укажите ФИО и телефон гостя.
2. При желании привяжите **хоста** (клиента клуба).
3. Введите оплату и способ.
4. Нажмите **Записать гостя**.

Справа — виджет **«Скоро заканчивается»** по абонементам.

## 4. Клиенты

### 4.1. Список

Раздел **Клиенты** (`/members/`).

![Список клиентов](assets/walkthrough/03-members-list.png)

- поиск и фильтры;
- переход в карточку по клику на клиента;
- создание нового клиента (кнопка / форма «новый»).

### 4.2. Карточка клиента

![Карточка клиента](assets/walkthrough/04-member-card.png)

В карточке:

- личные данные и контакты;
- текущий и прошлые абонементы;
- история оплат и визитов;
- доступ в ЛК (логин / выдача пароля);
- QR / номер карты для стойки;
- медсправка и связанные модули (PT и др.).

### 4.3. Выдать доступ в ЛК

1. Откройте карточку клиента.
2. Задайте или сбросьте пароль портала.
3. Сообщите клиенту логин (телефон / email / карта) и временный пароль.
4. Клиент входит на `/portal`.

## 5. Абонементы и оплаты

### 5.1. Планы абонементов

Раздел **Абонементы** → планы (`/memberships/plans`).

![Планы абонементов](assets/walkthrough/16-memberships.png)

Создавайте и редактируйте планы: срок, лимит визитов, цена, название.

### 5.2. Продажа абонемента

1. Откройте карточку клиента.
2. Выберите план и оформите продажу.
3. Проведите оплату.
4. Убедитесь, что статус абонемента **`active`**.

Другие статусы: `expiring`, `frozen`, `expired`. Заморозка / разморозка — из карточки или раздела абонементов.

### 5.3. Журнал оплат

Раздел **Оплаты** (`/memberships/payments`).

![Журнал оплат](assets/walkthrough/17-payments.png)

Видны сумма, способ, дата и комментарий. Та же история доступна в карточке клиента.

## 7. Личный кабинет клиента

### 7.1. Вход

URL: `/portal`.  
Клиент входит по телефону / email / номеру карты + паролю (пароль выдаёт staff).

![Вход в личный кабинет](assets/walkthrough/05-portal-login.png)

### 7.2. Главный экран ЛК

![Главный экран ЛК — карта и QR](assets/walkthrough/06-portal-home.png)

Клиент видит:

- digital membership card и статус абонемента;
- **QR-пропуск** для стойки;
- KPI посещений и 12-недельную активность;
- блок оплат и долга;
- лояльность, медсправку, PT-пакеты (если включены).

### 7.3. Запись на занятие

Прокрутите до каталога **«Доступные занятия»**.

![Каталог занятий и запись](assets/walkthrough/06-portal-booking.png)

1. Выберите занятие.
2. Нажмите **Записаться**.
3. Система проверяет абонемент и свободные места.
4. Занятие появляется в **«Мои записи»**.

![Мои записи в ЛК](assets/walkthrough/07-portal-my-bookings.png)

### 7.4. Отмена записи

![Отмена записи в ЛК](assets/walkthrough/11-portal-cancel.png)

- отмена только **своей** записи;
- не позднее лимита `portal_cancel_before_hours` (по умолчанию **2 часа** до старта);
- повторная запись на тот же слот не создаёт дубль;
- `member_id` берётся только из portal-session (подменить чужой ID нельзя).

## 8. Заявки из ЛК у staff

После записи клиента из портала:

1. Создаётся бронь с `source='portal'`.
2. Создаётся алерт `class_portal_booking`.
3. Owner/admin видят запись на `/dashboard` в блоке **«Новые записи из ЛК»**.

![Блок новых записей из ЛК на dashboard](assets/walkthrough/08-dashboard-portal-bookings.png)

В карточке занятия источник брони отображается явно (`portal` / `staff` / `waitlist`).

## 12. Опциональные модули

Стартовый пакет всегда включён: ресепшен, клиенты, абонементы, касса, расписание, тренеры, алерты, отчёты, dashboard, ЛК, сайт клуба, настройки.

Остальное **выключено по умолчанию**. Owner включает в **Настройки → Модули клуба**. Пункт появляется в меню только если модуль включён **и** у роли есть право.

| Ключ | Модуль | Назначение |
|------|--------|------------|
| `module_leads` | Лиды | Воронка до клиента |
| `module_loyalty` | Лояльность | Баллы / NPS |
| `module_pt` | PT | Персональные тренировки с тренером |
| `module_spa` | SPA/бар | Бар и доп. услуги |
| `module_lockers` | Шкафчики | Аренда шкафчиков |
| `module_corporate` | Корпоратив | B2B-контракты |
| `module_payments_online` | Онлайн-оплаты | Эквайринг (заглушка) |
| `module_zones` | Зоны | Зоны доступа при чекине |
| `module_messaging` | Сообщения | SMS / Telegram outbox |
| `module_branches` | Филиалы | Несколько точек |

Роль `reception` в seed не получает права на эти модули — только стойка, клиенты, чекин и расписание.

## 13. FAQ

### «Не открывается вход / 404 на `/login`»

Проверьте, что приложение запущено, `APP_PORT` верный, и в production настроен reverse-proxy. Для self-hosted пути **без** префикса клуба.

### «Клиент не может войти в ЛК»

Проверьте:

- аккаунт активен;
- выдан ли пароль портала в карточке;
- корректность логина (телефон / email / карта).

### «Не могу отменить запись»

Возможные причины:

- запись не ваша;
- меньше 2 часов до занятия;
- запись уже не в статусе `booked`.

### «Почему reception не видит dashboard?»

Это ожидаемо: роль `reception` работает через стойку `/reception/`.

### «Где документация и новости на сервере?»

- `/docs` — раздел документации  
- `/blog` — блог продукта  
- `/blog` — новости и релиз-ноты  

Markdown-источники: `docs/blog/*.md`, `docs/CHANGELOG.md`.

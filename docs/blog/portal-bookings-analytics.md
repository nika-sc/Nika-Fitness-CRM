# Что изменилось

- Запись из ЛК теперь создается с источником `portal`.
- Для staff создается алерт `class_portal_booking`.
- На owner/admin dashboard добавлены блоки:
  - новые записи из ЛК за 24 часа;
  - группы сегодня и заполняемость;
  - ближайшие записи клиентов;
  - отмены и no-show за 7 дней.

## Безопасность потока

- `member_id` для брони и отмены берется только из portal-session.
- Клиент не может отменить чужую запись.
- Поздняя отмена блокируется по правилу `portal_cancel_before_hours` (по умолчанию 2 часа).

## Что появилось в ЛК

- «Мои записи» с подтверждением и безопасной отменой.
- KPI по визитам + 12-недельная активность.
- Блок оплат и открытого долга.
- Карточки лояльности, медсправки и PT-пакетов.

## Почему это важно

Клиент видит прозрачный статус своих действий, а owner/admin получают измеримый входящий поток из портала прямо на главной CRM.

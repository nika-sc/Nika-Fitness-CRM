# Обновление сайта клуба

Появился полноценный публичный лендинг клуба:

- URL: `/club/<slug>/`
- публикация из CRM;
- секции «О клубе», «Тренеры», «Цены», «Расписание», «Контакты».

## Темы и фирменный стиль

- Пресеты темы;
- акцентный цвет;
- фон и прозрачность оверлея;
- поддержка gallery-фото.

## Что это даёт клубу

- Быстрый запуск страницы клуба без отдельного конструктора.
- Единый визуальный стиль CRM + ЛК + сайта.
- Прозрачная связка с карточками тренеров и групповым расписанием.

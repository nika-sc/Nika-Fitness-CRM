# Что изменилось

Разделили продукт на два контура яснее для пользователей и контрибьюторов.

## Публичный self-hosted

- Репозиторий [Nika-Fitness-CRM](https://github.com/nika-sc/Nika-Fitness-CRM) — только установка на своём сервере (Linux / Windows).
- Публикация снапшота: `tools/publish_public.py` (без SaaS-пакета и без инструкций облачной регистрации).
- README, SUPPORT, DEPLOY и security/contributing-оверлеи для OSS.

## Руководства со скриншотами

- [USER_GUIDE](../USER_GUIDE.md) — разделы CRM с экранами ресепшена, клиентов, расписания, ЛК и отчётов.
- [USER_WALKTHROUGH](../USER_WALKTHROUGH.md) — сценарий рабочего дня шаг за шагом.
- Скриншоты лежат в `docs/assets/walkthrough/`.

## Главная страница продукта

- На лендинге — галерея скриншотов CRM с увеличением по клику.
- Фон остаётся атмосферными фото клуба.
- Демо-ссылки на CRM, ЛК и сайт клуба сохранены в навигации и блоках входа.

## Граница публичной редакции

Мультитенантные компоненты сети клубов остаются в приватном контуре и не входят в публичный self-hosted снапшот.

# Новый движок оформления — страницы открываются быстрее

23 августа 2026 Nika Fitness CRM перешла на свой слой стилей. Функции клуба те же: ресепшен, абонементы, расписание, личный кабинет и сайт. Поменялось то, чем рисуется интерфейс и сколько лишнего браузер качает вместе со страницей.

## Зачем меняли

Раньше к экрану сотрудника, витрине и сайту клуба цеплялся чужой каркас админки. Он был тяжёлым даже там, где сайдбар не нужен. Теперь один собранный файл стилей на все поверхности: рабочее место, вход, документация, ЛК и сайт клуба.

Страницы стали легче, шапка одинаковая и плотнее, цвет клуба по-прежнему берётся из настроек.

## Что это значит для клуба

- Открывается быстрее: нет отдельной библиотеки вёрстки «на всякий случай».
- На телефоне меню витрины и сайта клуба своё, без чужих скриптов.
- Self-hosted: готовый CSS уже в репозитории. Node.js на сервере зала не нужен.
- Миграции базы не требуются. После обновления достаточно обновить файлы и перезапустить службу.

Сценарии дня не менялись. Если что-то выглядит иначе — это новый ритм шапки и кнопок, не другая логика чекина или записи.

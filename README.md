## Как пользоваться

1. Посмотрите [демо](https://fitness.nika-crm.ru/demo) — готовый клуб, вход без регистрации.
2. [Создайте свой клуб](https://fitness.nika-crm.ru/) — отдельная база, сразу можно работать.
3. **Подписка не нужна.** Сейчас программа бесплатная.

Документация на сайте: [fitness.nika-crm.ru/docs](https://fitness.nika-crm.ru/docs).

## Локальная установка

Самостоятельно ставить CRM на Linux, Windows или Docker **не нужно** — кода приложения в этом репозитории нет.

Если клубу нужен сервер **в зале**, пишите: сделаем установку **нашими силами** по запросу.

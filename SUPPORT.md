# Поддержка Nika Fitness CRM

## Сообщество

- Сначала документация: `docs/USER_GUIDE.md`, `docs/USER_WALKTHROUGH.md`, `docs/DEPLOY.md`.
- Баги и идеи — issues в GitHub.

## Установка

Поддерживается развёртывание на **своём сервере**:

- Linux / VPS: Docker, домен, HTTPS, бэкапы;
- Windows: локальный сервер в клубе, автозапуск, сеть зала.

Помощь с установкой — по запросу.

## Коммерческие услуги

Доработки, интеграции и адаптация процессов — **платные** услуги по согласованию.

## Что указать в обращении

- режим: Linux / Windows;
- ОС, Python, PostgreSQL, Docker (если есть);
- версия / commit;
- текст ошибки и traceback;
- шаги воспроизведения.

Контакты: `info@nika-sc.ru`.
